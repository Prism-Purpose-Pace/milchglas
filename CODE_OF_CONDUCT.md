# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. It applies to every project space: issues, pull requests,
discussions, reviews and any other communication about Milchglas.

In short: be respectful and constructive, assume good intent, and focus on the work.
Harassment, personal attacks and publishing other people's private information are not
tolerated.

## Reporting

Report unacceptable behaviour privately to the maintainer, [@philippsied](https://github.com/philippsied),
using the contact address on that GitHub profile. If you cannot reach the maintainer, or
the report concerns the maintainer, use GitHub's
[report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
function. Reports are handled confidentially.

## Enforcement

The maintainer follows the Contributor Covenant's enforcement guidelines (correction,
warning, temporary ban, permanent ban) and may remove, edit or reject contributions
that violate this code of conduct.
