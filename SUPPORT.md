# Support

Milchglas is a volunteer, single-maintainer project without paid support. Help happens
in public issues, on a best-effort basis. The project is pre-1.0: only the latest release
and `main` are supported.

## Before you ask

- [README.md](README.md): what Milchglas does and how it is configured.
- [docs/spec.md](docs/spec.md): scope, decisions and open questions; many "why not X?"
  answers live here.
- [docs/architecture.md](docs/architecture.md) and
  [docs/threat-model.md](docs/threat-model.md): how the parts fit together and what they
  protect against.

## Where to ask

- **Something behaves differently than documented:** open an issue with the bug report
  form.
- **The documentation leaves your question open:** that is a documentation gap; open a bug
  report and name the page.
- **An idea or a change in scope:** open an issue with the feature request form.
- **A security vulnerability:** never in public. Report it privately as described in
  [SECURITY.md](SECURITY.md).

Never paste real calendar data, feed URLs with tokens, hostnames of your servers or
credentials into an issue. Reproduce the problem with synthetic events.
